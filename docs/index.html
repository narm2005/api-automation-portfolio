Test framework

GraphQL + SOAP API automation

A Playwright and TypeScript framework that tests a modern GraphQL API and legacy SOAP services side by side. It checks the GraphQL errors array as well as HTTP status, handles SOAP 1.1 and 1.2 faults, runs an introspection-based check for breaking schema changes, and confirms that the GraphQL and SOAP systems agree on the same reference data.
